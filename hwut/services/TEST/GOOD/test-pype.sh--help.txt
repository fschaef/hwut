--- stdout, exit 0
STIMULUS: python3 -m hwut.services.pype --help
NAME
    hwut.pype -- run a pype SCRIPT over its input

USAGE
    hwut.pype [--trace] SCRIPT < input
    hwut.pype SYSTEM.pypes < input   (a system of scripts, wired)
    hwut.pype --draw [--svg] SYSTEM.pypes   (draw the system: ASCII; SVG)
    hwut.pype --example SCRIPT   (print generated example input)
    hwut.pype --dry-run SCRIPT   (check the script, read no input)
    hwut.pype --unit-types       (the unit types of 'quantity(...)')
    hwut.pype --units [<type>]   (the units, of one type where named)

DESCRIPTION
--trace: show, on stderr, input lines against the
    handlers they trigger, and the executed
    lines inside python blocks; gcc-style
    'file:line:' prefixes
--trace-plain: the same trace with a plain
    'TRACE|' line starter instead
SCRIPT may be followed by INPUT-FILE arguments,
    read in order as one stream instead of stdin
EXIT:     0
--- and nothing on stderr
<hwut-end>
