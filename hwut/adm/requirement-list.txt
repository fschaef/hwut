==============================================================================
WHAT WORKING ON hwut REQUIRES -- every tool, package and library
==============================================================================

ONE LIST, READ BY PEOPLE AND BY 'adm/requirement-check.sh'. A tool the
tree comes to need is entered HERE in the same change that needs it; the
development container ('adm/container/Containerfile') installs what this
list names.

    sh adm/requirement-check.sh         what stands on this machine, what
                                        is missing, and what goes red
                                        without it; exit 1 where a CENSUS
                                        requirement is missing

THE COLUMNS, separated by blanks; '#' opens a comment:

    kind      program   found on PATH
              python    a module Python imports
              library   a shared library the system's loader finds
    name      what is looked for
    need      census    'bin/hwut.run' over the tree is red without it
              road      one road of hwut wants it; the census does not
    debian    the Debian/Ubuntu package ('pip:<name>' for a Python one)
    for       who needs it
