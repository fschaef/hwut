==============================================================================
WHAT WORKING ON hwut REQUIRES -- every tool, package and library
==============================================================================

ONE LIST, READ BY PEOPLE AND BY 'adm/requirement-check.sh'. A tool the
tree comes to need is entered HERE in the same change that needs it; the
development container ('adm/container/Containerfile') installs what this
list names.

    sh adm/requirement-check.sh         what stands on this machine, what
                                        is missing, and what goes red
                                        without it; exit 1 where a CENSUS
                                        requirement is missing

THE COLUMNS, separated by blanks; '#' opens a comment:

    kind      program   found on PATH
              python    a module Python imports
              library   a shared library the system's loader finds
              perl      a module Perl loads ('perl -M<name>')
              header    a C header the compiler finds ('#include <name>')
    name      what is looked for; for a 'python' row the module, and
              '>=<version>' the oldest version measured to work, as pip
              numbers it
    need      census    'bin/hwut.run' over the tree is red without it
              road      one road of hwut wants it; the census does not
              support:<language>,...
                        the test writing support of those languages and
                        their demonstrations ('support/') are red without
                        it -- the rest of the census is not; 'all' names
                        every language but Python
    debian    the Debian/Ubuntu package; 'pip:<name>' where only pip has
              it. '>=<version>' the oldest version measured to work, as
              DEBIAN numbers it ('regex' 2022.10.31 is Debian's
              0.1.20221031). MEASURED 2026-10-16: the census green with
              the versions of Ubuntu 24.04; red with typeguard 2.13
    for       who needs it, on ONE line: for a user's requirement
              'hwut.help' says it after 'MISSING: ... --', so it is said
              in a user's words; a developer's note goes on a '#' line
              beneath

WHAT A USER'S INSTALLATION REQUIRES is read off this list, never restated
(adm/WORK/spec/24-installation-packages.txt): the 'python' rows of need
'census' are the wheel's dependencies -- the 'name' column as it stands -- and their
'debian' column, with 'python3' and 'libvterm0', the Debian package's
'Depends'. 'hwut.help' reads the same rows to name what is missing.

THE TEST WRITING SUPPORT AND ITS DEMONSTRATIONS ('support/', E-217). The
versions are those MEASURED 2026-11-01 (Ubuntu 24.04; Go, node, Rust and
PowerShell from their own releases): every port 47 ok, every demonstration
27 ok. Older ones are not measured, and some are known not to do: Go below
the 'go.mod's 1.24, node below 22.5 (no 'node:sqlite'), a JDK below 21 (no
FFM preview). 'adm/container/Containerfile' installs exactly these.
