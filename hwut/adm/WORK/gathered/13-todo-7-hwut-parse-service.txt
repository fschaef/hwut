todo-7  THE 'hwut.parse' SERVICE
______________________________________________________________________________

DECIDED (R-9, R-29). BUILT, except the command line itself.

    hwut.parse <source file>    scan for the trigger token, extract the
                                specification, check, resolve, print
    hwut.parse                  act as the explorer: 'hwut.conf' first,
                                then the files

It checks the syntax, RESOLVES the defaults, and prints the complete
configuration, prettily -- what the framework READ, not what was written.

     construction.

     while the three sources still stand apart, and annotated in a
     HOCON comment only where the value is not this choice's own word:
     'app', 'hwut.conf:<line>', '--hwut-info', 'default' (R-51, R-53).
  2b '--no-default' drops every line that reads 'default'; a scope
     whose every leaf would go is dropped whole.
  2d '--provenance' names the PLACE of every stated value; '--gnu'
     names it in the GNU error format, 'file:line:column' (R-67).
  2c The printed form IS the specification language (R-50): what is
     printed can be read back.

  4  TEST/test-printer.py: file, origins, directory, faults.
