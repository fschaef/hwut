1  WHAT PHILOSOPHY 1.1 ACTUALLY SAYS

It holds THE POLE and THE SYMMETRY together, and they are about
different things:

    THE POLE is about WHICH member of GOOD is accepted.
        "TO ACCEPT IS TO DECLARE THE POLE OF GOODNESS: not any member
        of GOOD, but the one all the others are arranged around."
        Its gain is measurable and stated: the required tolerance falls
        from diameter(D(GOOD)) to radius(D(GOOD)) -- roughly half.

    THE SYMMETRY is about THE FORM OF Eq.
        "THE VERDICT MUST NOT DEPEND ON WHICH GOOD BEHAVIOUR WAS
        ACCEPTED... Eq(D(b0), D(b), T) is not a function of b0."

And then, in the paragraph headed 'Two demands follow', it says the
thing that settles this fork outright:

        Eq MUST BE SYMMETRIC. 'within r of the NOMINAL' is not: it
        makes the nominal an anchor, and the criterion is NOT EVEN
        WELL POSED. A relative tolerance must be relative to something
        symmetric -- THE LARGER MAGNITUDE, or the mean -- or be
        absolute.

So the document ANTICIPATED the defence I offered and named it as the
error. 'The band belongs to the nominal' is the exact phrase
PHILOSOPHY calls ill-posed.

Nor is the pole weakened by symmetry. The document keeps both: every
comparison has the same fixed anchor (which is why non-transitivity
never bites -- "nothing is ever chained"), AND the band's WIDTH is
computed symmetrically. Anchor and width are separate choices; I had
collapsed them.

2  WHAT THE CODE DOES, MEASURED

'engine/compare/reading/line_element.py', LineElementNumber:

    __init__     self.epsilon = abs(self.number) * ratio
                 -- stored PER ELEMENT, from that element's own
                 magnitude. The comment says "tolerance band radius
                 when this element serves as pole (nominal)".

    compare      abs(self.number - nominal.number) <= nominal.epsilon
    cost         error = max(|s - n| - nominal.epsilon, 0.0)

Both readings take the band from THE NOMINAL ALONE. So

    Eq(s, n)  uses  |n| * ratio
    Eq(n, s)  uses  |s| * ratio

which is 'within r of the NOMINAL' precisely, and therefore the form
PHILOSOPHY 1.1 refuses.

THE UNSIGNED HALF IS GENUINELY FIXED: 'abs()' is present, and the
comment "a radius carries no sign" records why. That half of todo-19
is closed and should be struck when the rest is settled.

3  THE FIX IS ALREADY HALF-WRITTEN

'edit_distance_relative' ALREADY COMPUTES the symmetric magnitude, one
line below the place that needs it:

        error = max(abs(self.number - nominal.number)
                    - nominal.epsilon, 0.0)      <- asymmetric band
        mag   = max(abs(self.number), abs(nominal.number))   <- symmetric
        return min(1.0, error / mag)

'mag' is exactly what PHILOSOPHY names ("the larger magnitude"). It is
used for the SCALE of the cost and not for the WIDTH of the band. What
todo-19's OWED list asks for --

        'max(abs(s), abs(n)) * ratio' at comparison time,
        not stored per element

-- is that same quantity, moved one line up and multiplied by the
ratio.

WHAT IT COSTS, honestly:
  - 'epsilon' stops being a stored slot and becomes a computed value;
    the ratio must then be reachable at comparison time, which it is
    not today (it is consumed in '__init__' and discarded).
  - the pole's ROLE is unchanged: the nominal is still the anchor,
    still the thing every subject is compared against. Only the WIDTH
    calculation changes.
  - Contract 3 must be re-checked: 'equivalent == True' iff
    'cost == 0.0' at the boundary. Both readings must take the new
    band or they will disagree exactly at the edge -- which is the one
    place the contract is testable.
  - test choices, as todo-19 already lists: a negative pair inside the
    band is TOLERATED; d(x,y) == d(y,x) for signed pairs across the
    boundary.
