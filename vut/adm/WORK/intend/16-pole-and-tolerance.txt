1  THE RULING, IN FRANK-RENE'S OWN FORMULATION

    Let d(b) be the DESCRIPTION FUNCTION that a test provides for the
    behaviour b:

        d :  behaviour  ->  description

    Then d(b_nominal) is the description of the NOMINAL BEHAVIOUR --
    in our case, the recorded GOOD file.

    The equivalence function operates ON DESCRIPTIONS, never on
    behaviour:

        Eq( d(b_subject),  d(b_nominal),  t )

    where the tolerance is

        t( d(b_nominal) )

    -- a function of the NOMINAL'S DESCRIPTION. We always operate on
    descriptions and never on actual behaviour, so the tolerance is
    derived from the description too.

    NOMINALS ARE POLES. SUBJECTS ARE TRABANTS. The first argument to
    Eq is the description of the SUBJECT's behaviour, the second the
    description of the NOMINAL's.

______________________________________________________________________________

2  WHAT FOLLOWS, AND WHAT DOES NOT

THE ROLES ARE ASYMMETRIC BY CONSTRUCTION. That is what 'pole' and
'trabant' mean. Eq is only ever called subject-against-nominal;
'Eq(d(b_nominal), d(b_subject), t)' is not a query the system makes,
so what such a call would answer is idle.

THE POLE SETS THE SCALE. Since t is a function of d(b_nominal), the
band is the NOMINAL'S. 'nominal.epsilon' in
'compare/reading/line_element.py' IS THE DOCTRINE EXPRESSED CORRECTLY,
not a defect.

A SYMMETRIC BAND IS WORSE, not merely unnecessary. Under
'max(|s|, |n|) * ratio' A SUBJECT THAT DRIFTS AWAY FROM THE POLE
WIDENS ITS OWN TOLERANCE: the further it strays, the more leniency it
buys. That is incoherent with the pole -- a declared centre whose
scale is set by the thing being measured against it is not a centre.

TWO NOMINALS DISAGREEING ABOUT ONE SUBJECT IS NOT A DEFECT OF Eq. It
is the falsification 1.1 itself describes: the accepted run was not
the pole. The answer is to move the nominal toward the centre, or to
widen d until the spread vanishes -- never to widen t.

        "the danger is not that the rule is missing; it is that

     Whatever replaces 3.1 should keep that and drop the remedy.

3.3  THE NOTATION. Where the tolerance is written, it is 't' or
     't(b, b_nominal)'. Both are wrong for the same reason: they
     suggest the tolerance is a function of BEHAVIOUR, or of the
     subject. It is

        t( d(b_nominal) )

     -- of the nominal's DESCRIPTION alone. Sweep the notation with
     the paragraph.

3.4  'ACCEPTANCE IS NOT A FREE CHOICE' AND THE POLE PASSAGE STAND
     UNCHANGED. The diameter/radius argument, the margin condition,
     and the falsifiability of the acceptance hypothesis are all

5  THE ONE THING WORTH KEEPING FROM THE WHOLE EXCHANGE

The margin condition is CHECKABLE and nothing checks it:

    radius( d(GOOD) )  <=  t  <  distance( pole, d(BAD) )

'hwut.stability --repeat' already measures the spread of good runs,
which is radius. A suite choice comparing that spread against the
standing tolerance would be the check 1.1 says is missing -- and it
would catch the real failure, which is a nominal accepted near the
edge rather than at the centre.

durable residue of a discussion that was otherwise misplaced. It

6  CLOSED -- THE NOTATION IS 'D'

The ruling was stated with 'd' as the DESCRIPTION function:

        d :  behaviour  ->  description        t( d(b_nominal) )

'adm/PHILOSOPHY.txt' already uses BOTH letters, and differently:

        D   the transformation behaviour -> description   (line 38)
        d   THE DISTANCE that Eq thresholds               (line 175)
            "Let d be the distance Eq thresholds, so that
             Eq(x, y, T) holds exactly when d(x, y) <= T"

So 'd' means DESCRIPTION in the ruling and DISTANCE in the document,
and both appear in section 1.1 within forty lines of each other.

THE EDIT USED THE DOCUMENT'S OWN LETTERS -- 'T = t( D(b_nominal) )' with
a capital D -- so that 1.1 stays internally consistent and no reader
meets two meanings of one symbol. THE RULING'S SUBSTANCE IS UNCHANGED
by the choice of letter; only the letter differs from how it was
stated.
