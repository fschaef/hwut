WHAT THIS IS. 'TODO.txt' is the ONE LIST and says of itself: "not a
schedule and not a priority order". This file is the ORDER in which to
work through it -- printed and ticked. Every item here carries the id
it has in TODO.txt (A-4, G-1, ...) or in 'review-r10.txt' (r-10a ...);

run. This file holds no evidence of its own. When an item is struck in
TODO.txt it is struck here; when TODO.txt gets a version 17, this file
gets a version 2 or a note saying which ids moved.

THE RULE OF THE ORDER, so a later reader can re-sort on the same rule:

    TIER 1  a GREEN RESULT OR AN ACCEPTANCE CAN LIE -- the author sees
            [OK] or 'blessed' and it is not what he stated
    TIER 2  BREAKS WHEN USED AS DOCUMENTED -- a word the manual or a
            ruling offers, written in a page, fails or crashes
    TIER 3  BLOCKS REAL USE, or DECIDED AND UNBUILT with no block
    TIER 4  THE RECORD IS WRONG -- rulings nowhere, entries overtaken,
            names moved; cheap, and each one misled this audit once
    TIER 5  WAITING ON A RULING -- the user's word, then labour
    TIER 6  A MEASUREMENT ONLY THE USER'S MACHINE CAN GIVE
    TIER 7  HARMLESS WHILE IT WAITS

Within a tier: what more people would meet comes first. The order is
the audit's judgement (2026-10-06), NOT a ruling; the user asked for it
to be sorted, he did not confirm each place.

    [ ] ID   TITLE
