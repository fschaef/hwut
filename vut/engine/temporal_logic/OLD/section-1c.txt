STABILITY AND THE LEAST FIXED POINT

This system eliminates logical instability through Idempotence and
Monotonicity. An implication is a constructive force; it can only add to the
set of existing events. Once an event is brought into existence within "The
Now," no subsequent implication can remove it.

Because the logic of the Obsnow forbids the negation of current events, the set
of existing events is strictly monotonically increasing during the calculation
of a Jiffy. This guarantees that the chain of implications inevitably reaches a
Least Fixed Point: a stable state where all valid implications are satisfied
and the set ceases to change.

Consequently, circular dependencies (e.g., 'A <= B' and 'B <= A') do not
produce infinite loops or oscillation. Instead, they resolve into the
instantaneous, stable existence of the union of the participants (both A and
 B).

Stability defines the Jiffy. The moment (in logical no-time), when the set of
events stops expanding, the Jiffy is complete, and the set enters the record of
immutable history.
