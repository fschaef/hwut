# 3. Data Model & Temporal Semantics

This section defines the data structures observed by the engine and the precise semantics of the operators used to reason about them.

### 3.1 The Event Object

Events are the atoms of the system. They are structured, typed, and immutable
once ingested.

* **Structure:** An event `E` consists of:
    * **Header (Metadata):** Reserved fields managed by the Engine (e.g., `@timestamp`, `@seq_id`, `@source`).
    * **Payload (User Data):** A structured map (JSON-like) containing the SUT's data.
* **Typing:** The engine supports primitives (Boolean, Integer, Float, String) and collections (Lists, Maps).
* **Access:** Fields are accessed via dot-notation (e.g., `Event.payload.status`).

### 3.2 Derived State: Meta-Events & Fixpoints

The engine allows the definition of **Meta-Events**—logical signals derived
from raw events (e.g., `IsActive := Status == "ON"`).

* **Evaluation Phase:** Meta-events are calculated *after* event ingestion but *before* Rule evaluation.
* **The Fixpoint Guarantee:**
    * If Meta-Event `B` depends on `A`, the engine resolves dependencies to a stable state.
    * **Circularity:** Direct circular definitions (e.g., `A := not A`) are detected and flagged as a "Logic Loop" error during compilation.

### 3.3 Temporal Operator Semantics

To ensure tests are unambiguous, we define the exact meaning of temporal
keywords.

#### 3.3.1 Simultaneity (`and`)

* **Definition:** The expression `A and B` is true if and only if `A` is true **AND** `B` is true within the **same Jiffy**.
* **Contrast:** It does *not* imply sequence. If `A` happens at `T=1` and `B` at `T=2`, `A and B` is False.

#### 3.3.2 Historical Existence (`ever`, `never`)

* `ever(P)`: True if predicate `P` was True in *any* Jiffy from `T=0` to `T=NOW`.
* `never(P)`: Equivalent to `not ever(P)`.
* **Scope:** These operators scan the *entire* immutable history (see 1.2).

#### 3.3.3 Interval Logic (`since`, `until`)

* `P since Q`: True if `Q` occurred in the past, and `P` has been true in *every* Jiffy since then (up to and including NOW).
* `P until Q`: (Used primarily in Scopes) True if `P` holds true, and the scope terminates successfully when `Q` becomes true.

#### 3.3.4 Time Deltas (`time`)

* `time(Event)`: Returns the physical timestamp of the *most recent* occurrence of `Event`.
* **Usage:** `time() - time(Request) > 5.0s`.
* **Safety:** If `Event` has never occurred, `time(Event)` returns a special `NIL` value that propagates safely (i.e., comparisons return False, not crash).

### 3.4 The Binding Constraint

To distinguish between "checking" and "searching," we enforce a strict separation of binding:

* **Pattern Matching (`==`):** `Request.id == 100`. Checks if the value *equals* 100.
* **Variable Binding (`=>`):** `Request.id => ID`. Captures the value into variable `ID`.
* **Restriction:** Binding (`=>`) is **prohibited** inside pure history quantifiers like `ever()` or `never()` within the global scope.
    * *Reasoning:* This prevents implicit O(N^2) searches.
    * *Solution:* Bindings are exclusively allowed in **Scope Triggers** (see Section 4), where the engine can optimize the search index.
