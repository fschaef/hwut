In an environment of evolving implications, a purely synchronic Composition is
insufficient to govern dynamic, generative processes. We cannot associate a
grouping of discernibles with the truth modality $\top$ if their constituent
events have not yet been logically established via implication. To do so would
allow the Ontic Engine to reference the result of un-established implications
\textit{before} they are generated. 

In mathematical logic, this illicit pre-referencing is known as
\textbf{Impredicativity}. Russell's antinomy of the ``set of all sets that do
not contain themselves'' arises precisely from this structural flaw. By
strictly enforcing \textbf{Predicativity}---where an entity can only be defined
by quantifying over already-established elements---our framework structurally
prevents such paradoxes without relying on ad-hoc axiomatic patches.

To establish a stable, dynamic definition of a Set, we must track how
Compositions relate to shared core characteristics. A Composition Event
$e_{co}$ inherently implies a new relational event for each distinct
discernible $\delta_\wedge$ present within its composition, asserting the
structural property of ``containing'' that discernible:

\begin{equation}
    e_{co} \implies \langle \top, \text{Has}(\delta_\wedge, e_{co}) \rangle \quad \text{for every } \delta_\wedge \in \delta_{co}
\end{equation}

Through the primordial faculty of Equivalence, the Ontic Engine can evaluate a secondary Composition consisting entirely of these Has events. When multiple distinct Composition Events $(e_{co,0}, e_{co,1}, \dots, e_{co,n})$ share the equivalent characteristic $\delta_\wedge$, their co-existence structurally implies a unified informational substance: the Set Event $e_\wedge$.

\begin{equation}
    e_\wedge = \langle \top, \text{Share}(\delta_\wedge, e_{co,0}, e_{co,1}, \dots, e_{co,n}) \rangle
\end{equation}

\begin{formalism}[Set and Set Event]
    A \textbf{Set} is the generative implication rule that applies Equivalence and Differentiation across established Compositions to identify a shared characteristic $\delta_\wedge$. 
    
    The \textbf{Set Event} $e_\wedge$ is the dynamic informational substance instantiated by this rule at a particular logical step. The generative operation exhausts---and the Set Event becomes complete---exactly when no further $e_{co}$ events containing $\delta_\wedge$ can be instantiated within the current Synthetic Interstice.
\end{formalism}
