EVENTS, META-EVENTS, HISTORY, AND TSCOPE — PRECISE SEMANTICS
==========================================================

An EVENT is a *predicate over NOW* and lives for exactly one **jiffy**.
A jiffy is a time span smaller than any quantifiable resolution. EVENTS have
no duration and do not persist. They are true only in the jiffy in which they
occur.

A **causal (external) event** is an EVENT injected by the test stream.
A **META-EVENT** is not a new temporal object; it is a *derived perspective on
NOW*. META-EVENTS are predicates evaluated on the same NOW and therefore share
the same lifetime (one jiffy). They never create additional temporal layers.

It is crucial to distinguish EVENTS from *state facts*:

- `HEARTS == 0` is **not an event**.
  It is a persistent state fact derived from history.
- The EVENT is the jiffy in which `HEARTS` *becomes* `0`.
  Only that transition can be an EVENT in NOW.

HISTORY is not composed of events. HISTORY is *knowledge*.
Expressions such as `ever(X)`, `never(X)`, or `since(...)` query the occurrence
database. They do not “happen” and are never true *by themselves* in NOW.

However, a HISTORY predicate may participate in forming an EVENT predicate.
A valid EVENT predicate is therefore:

  EVENT ∧ HISTORY

For example:

  WATER_DROP_ON_GROUND and ever(SEED_ON_GROUND)

This expression is an EVENT predicate:
- `WATER_DROP_ON_GROUND` anchors the predicate in NOW (one jiffy).
- `ever(SEED_ON_GROUND)` restricts it using HISTORY.
The conjunction as a whole is true for exactly one jiffy and thus qualifies
as an EVENT. HISTORY predicates are not allowed to stand alone; they must be
conjoined with an EVENT.

With this model, a temporal scope

  on EVENT until EVENT:

is implemented purely as *recognition*. At each jiffy, the TSCOPE evaluates its
EVENT predicates against NOW (with optional HISTORY queries). No events are
created by TSCOPEs; they only recognize whether conditions are present.

CIRCULARITY RESOLUTION
---------------------

Circularity is resolved by a strict temporal rule:

- EVENTS (causal or meta) exist only in the current jiffy.
- ACTIONS triggered by TSCOPE entry or exit are executed in a *later jiffy*.
- Therefore, actions cannot create EVENTS that are visible in the same NOW
  that triggered them.

Circularity detection is reduced to state repetition:
If the internal engine state (user state `G`, active TSCOPE set, pending action
structure) is reached twice *without an intervening external event*, the system
has entered an infinite internal loop. This condition is deterministic and can
be detected reliably.

This model cleanly separates:
- observation (NOW),
- memory (HISTORY),
- recognition (TSCOPE),
- judgment (RULES),
- and effect (ACTIONS),

yielding a deterministic, analyzable, and non-ambiguous temporal engine.
