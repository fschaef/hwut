SEMANTIC LAYER -- BUILD PROGRESS
================================

THE SKELETON IS COMPLETE AND END-TO-END FUNCTIONAL. Real source flows through
load -> build -> resolve+drain -> checks -> cascade and yields a frozen
ResolvedProgram, gating to None on any staged error. All modules are tested
against the REAL parser + FakeLuauOracle; no AST is fabricated. GOOD-recorded,
byte-exact.
