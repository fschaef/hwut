todo-1  METHOD CATALOGUE PER RECEIVER TYPE  (pass-2 table)
===============================================================================
SCOPE     semantic (pass-2). Mechanism decided; the table is to be authored.

DECIDED:
    The grammar admits any '.id(args)' postfix; it does NOT name methods. The
    per-receiver-type catalogue is a pass-2 table keyed by receiver type. Kind
    checking extends F-5/expression typing: a method's receiver type, argument
    count, and argument kinds are checked against the table entry.

TO IMPLEMENT:
    The table itself -- for each built-in receiver type, the legal methods,
    each with its argument arity and kinds and its result type. Known members
    to seat (from the guards the bracket condition replaced):
      - string : glob, match, ...
      - list   : len, ...
      - dict   : has, keys, values, ...
      - watcher queries : has, any, all, ...
    A '.id' with no '(' is a member READ; a '.id(args)' is a method CALL
    (args=None on the AST marks a bare member read on a call result).

    An unknown method on a receiver, or a wrong arity/kind, is a pass-2 error.
