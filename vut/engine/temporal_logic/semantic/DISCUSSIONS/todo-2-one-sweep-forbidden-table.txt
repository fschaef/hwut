todo-2  'one-sweep' FORBIDDEN-CONSTRUCT TABLE  (pass-2)
===============================================================================
SCOPE     semantic (pass-2). Mechanism and the row are decided; wire the check.

DECIDED:
    A 'do:' sweep reference carries the advisory role hint '<do-sweep(one-sweep)>'
    (parser D-10). Pass 2 reads the role and looks the profile up in a
    FORBIDDEN-CONSTRUCT TABLE (role -> the step kinds fatal in that role). The
    grammar enforces nothing; a new sweep context is a new table row.

    The 'one-sweep' row (a 'do:' body has NO heartbeat) forbids the
    tick-anchored forms that cannot progress without a recurring clock:
      - 'while:'              -- needs the tick to advance between iterations;
      - a PACED bare event    -- enters the cascade at a tick boundary (F-13);
      - 'wait:' / 'select:'   -- suspend until a future cause fires.
    Valid in one-sweep: 'instant:', the four mutations + container writes,
    spawn:/unspawn:/arm:, 'if:'/'elif:'/'else:', '{ luau }' segments.

TO IMPLEMENT:

    Each forbidden occurrence is a pass-2 error [SWEEP], reported against the
    step.
