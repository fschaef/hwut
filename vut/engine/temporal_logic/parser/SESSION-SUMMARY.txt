VUT PARSER -- SESSION SUMMARY (LL(2) migration + cause/effect reuse)
====================================================================

This is the COMPLETE parser tree with every change from this session applied.

ENGINE: LL(1) -> LL(2)
  - core/ll2_engine.py is the production engine (rule_parser.py imports it).
  - core/ll2_grammar_ast.py: FIRST_2 sets, two-token lookahead. The {(,)} ->
    {()} import bug is fixed. choose_alt is TWO-PASS: a full 2-token pair match
    strictly precedes a length-1 (single-token) match -- the fix that makes the
    'id' vs 'id =' style distinction work.
  - core/combinators.py is parameterised by node module (compile_element(...,
    nodes=)); default is ll2_grammar_ast.
  - core/ll1_engine.py.unused, core/grammar_ast.py.unused: the retired LL(1)
    files, kept for archeology (also in ll1-deprecated.zip). No live importers.

GRAMMAR / ACTIONS / AST
  - <arg> is the WIDE form: '<rvalue> | id = <rvalue>' (LL(2); the one rule that
    needs the second token). _build_arg, _build_spawn (positional, not type-
    spotted), _build_dotted_name (-> list[str]) updated; dead builders removed.
  - fwd-kind accepts 'mode' as a type-name ('X is: mode' parses).
  - NEW FEATURE -- named cause/effect definitions and references:
        cause: NAME(params) on: <cause>          (cause-def)
        effect: NAME => <effect> [=> <effect>]*   (effect-def)
        on: NAME(args) => NAME                    (cause-ref + effect-ref)
    'on:' and '=>' are signals even inside definitions. Cause-ref carries parens;
    effect-ref is a bare single name. Both ref/inline distinctions are decided by
    the SECOND token (LL(2)). New AST: CauseDef, EffectDef, CauseRef, EffectRef.
    Resolution/binding is deferred to pass-2.

ENGINE FINDING (for DISCUSSIONS.txt)
  TERMINAL_DB is process-global; tier-6 regex terminals match in DECLARATION
  order, so two regex terminals with overlapping languages are order-dependent --
  a toy grammar's regex can be silently shadowed. Core tests use '@'-prefixed
  terminals to avoid it. Worth an explicit note and possibly a guard.
