sequenceDiagram
    autonumber
    participant W as THE WORLD (SUT)
    participant N as THE NOW (Time)
    participant L as LOCO (Logic)
    participant H as HISTORY (Entropy)
    participant A as AGENT (Emergence)

    Note over W, A: JIFFY [N] (The Spark)
    W->>N: Emit Event: LOGIN (User: Bob)
    
    rect rgb(240, 248, 255)
        note right of N: Phase 1: Judgment
        N->>L: Trigger LOCO "Check_Login"
        L->>H: Query: never(BANNED_BOB)
        H-->>L: Result: TRUE
        L->>N: Imply: SUCCESS (Valid Login)
    end
    
    rect rgb(255, 240, 245)
        note right of N: Phase 2: Wake Up
        N->>A: Trigger AGENT "User_Session"
        Note right of A: Agent Wakes & Latches Event
    end

    Note over W, A: JIFFY [N+1] (The Void & The Reaction)
    Note right of N: Event LOGIN perishes -> Moves to History
    
    rect rgb(240, 255, 240)
        note right of N: Phase 3: Filling the Void
        A->>H: Query: attributes_of(LOGIN_N)
        A->>A: Update TwinWorld State (Session=Active)
        A->>N: Inject Event: WELCOME_MESSAGE
    end

    Note over W, A: JIFFY [N+2] (The Result)
    N->>W: Route Event: WELCOME_MESSAGE
    Note right of N: Cycle Complete.
