TWIN WORLD
==========

Definition:

    A 'TwinWorld' is a stateful simulation implemented by the test 
    designed. It provides data context for the temporal evolvement 
    of the test. 

It may hosts a synchronous "Digital Twin" of the WORLD, authorative boundaries,
and support functions to judge the WORLD behavior. It evolves through Jiffies.
It may act as an Oracle (quote), but its functionalities exceed it.

1. DATA ENCAPSULATION:

   The "Twin World contains "Reference Agents"—Lua objects that mirror WORLD
   entities. Each agent maintains its own internal variables, state machines,
   and validation logic.

2. SYNCHRONOUS EVOLVEMENT:

   Every state change in TwinWorld occurs within the Jiffy Calculus (t + ε). This ensures the "Virtual State" is always logically aligned with the "Reported Event," preventing race conditions between the monitor and the reference model.

3. PREDICATE DELEGATION:

   Temporal Guards delegate data-heavy assertions to TwinWorld Agents. A Guard enforces the "When" (Sequence), while the TwinWorld Agent enforces the "What" (Integrity).

4. FEEDBACK LOOP (META-EVENTS):

   TwinWorld can influence the Rule Space by synthesizing "State-Triggered Events." When a virtual agent's internal logic detects a boundary breach (e.g., { npc.power > max }), it injects a new event into the next Jiffy.

5. INJECTION:

   The TwinWorld has direct access to the INJECTION hub. This allows Reference Agents to not only monitor but also act—injecting command events or stimuli back into the WORLD to drive the test toward specific edge cases or to respond to detected behaviors.

Mathematical Definition
-----------------------

Let the RULE SPACE be defined as a tuple (G, W, I, ε), where:

1. THE STATE SPACE (S):
   The TwinWorld state S_w is the product of all active Reference Agent states: 
   S_w = A_1 × A_2 × ... × A_n.

2. THE TRANSITION FUNCTION (δ):
   The evolution of the TwinWorld through a Jiffy (ε) is defined by:
   δ: S_w × E → S_w
   Where E is the set of events (External, Meta-Events, or Injected).

3. THE INJECTION MAPPING (γ):
   The TwinWorld's ability to influence the WORLD is defined by an injection 
   function γ:
   γ(S_w, E) → E_inj
   Where E_inj is a stimulus injected into the WORLD's physical input stream 
   at the next available Jiffy.

4. THE TEMPORAL COINCIDENCE:
   For any physical timestamp T, the TwinWorld evolves through a finite 
   sequence of logical states:

   S_w(T, 0ε) ≺ S_w(T, 1ε) ≺ ... ≺ S_w(T, nε)

   The "Zero-Width" property ensures that for the WORLD, the state S_w(T, nε) 
   is reached before the physical clock advances to T + Δt.
