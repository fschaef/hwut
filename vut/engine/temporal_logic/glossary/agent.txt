# 8.15 THE AGENT 

Definition:

    An AGENT is a persistent entity within the TWIN WORLD. It acts as a 
    temporal bridge: it captures the impulse of an event in one Jiffy 
    and converts it into state changes or new injections in the next.

An AGENT does not see "The Now", it sees history. If an agent refers
to an event, it refers to it by queries to history:

   last(Event) -> Event attributes or nil
   ever(event, since=, until=) -> True, False
   never(event, since=, until=) -> True, False
   that(event, with=attributes) -> Event attributes or nil

An agent has no access to "The Now" and cannot send events. It can only
set a state in the TWIN WORLD, that causes an event in "The Now".


The Jiffy Rhythm
----------------

* Jiffy 'i':   EVENT is caused

* Jiffy 'i+1': EVENT exists in NOW
               Implications of EVENT exist in NOW          

* Jiffy 'i+2': EVENT ceases to exist in NOW and enters history.
               history of EVENT is visible in TWIN WORLD
               AGENTS perceive TWIN WORLD

* Jiffy 'i+3': AGENTS act in TWIN WORLD, possibly cause EVENT

* ...
