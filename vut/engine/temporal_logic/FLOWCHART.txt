TRANSPILATION PIPELINE
======================

       EXTERNAL INPUT
       ┌───────────────┐
       │  source_text  │     the .vut rule-file text
       └──────┬────────┘
              │   
              ▼
  ╔═══════════════════════╗
  ║      (1) PARSER       ║   parse(source_text, oracle, reporter)
  ║   text  ->  tree      ║   luau --> LuauOracle: "where does this {luau} span end?"
  ╚═══════════╤═══════════╝
              │ produces
              ▼
        ┌───────────┐        tree of TopLevel items in source order.
        │  RuleFile │        Names are still bare STRINGS (unresolved).
        │   (AST)   │        Luau bodies are still OPAQUE TEXT spans.
        └─────┬─────┘        (may be PARTIAL if errors were recovered)
              │
              ▼
  ╔═══════════════════════╗
  ║   (2) SEMANTIC LAYER  ║   resolve(rule_file, reporter)
  ║   tree -> tree+links  ║   builds scope tree, resolves every name,
  ╚═══════════╤═══════════╝   mounts includes, runs constraint checks
              │ produces
              ▼
     ┌──────────────────┐      AST PLUS:
     │  ResolvedProgram │      - scope tree (every defined name + where)
     │  (AST + answers) │      - per-reference resolution (symbol, FQN, kind)
     └────────┬─────────┘      - include-mount results
              │                Luau bodies STILL opaque (untouched here).
              ▼
  ╔═══════════════════════╗
  ║  (3) LUAU-SPAN CHECK  ║    check_luau(resolved_program, ...)
  ║  opaque -> validated  ║    parse each {luau} as Luau, confirm bindings
  ╚═══════════╤═══════════╝    (event/mode/sm/mg) in scope, build location map
              │ produces
              ▼
    ┌────────────────────┐     ResolvedProgram PLUS:
    │    LuauChecked     │     - each Luau span validated
    │ (ready for codegen)│     - source<->target location map established
    └─────────┬──────────┘
              │
              ▼
  ╔═══════════════════════╗
  ║   (4) CODE GENERATOR  ║   
  ║   ready -> Luau text  ║
  ╚═══════════╤═══════════╝
              │ 
              ▼
       ┌──────────────┐
       │  Luau source │  target program
       └──────────────┘


THE SHARED SIDE-CHANNEL 
(every unit writes to it, nobody returns errors inline)
───────────────────────────────────────────────────────

        (1)        (2)         (3)         (4)
         │          │           │           │
         └────┬─────┴─────┬─────┴─────┬─────┘
              ▼           ▼           ▼
        ╔════════════════════════════════════╗
        ║       DiagnosticReporter           ║   accumulator of
        ║  (syntax | semantic | luau | ...)  ║   Diagnostic(phase, severity,
        ╚════════════════════════════════════╝   message, source_offset)
                          │
                          ▼
               user-facing error list
