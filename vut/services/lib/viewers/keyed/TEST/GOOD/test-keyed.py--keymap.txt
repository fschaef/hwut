P-20/P-21/P-22: the table is the keymap

-- the help screen IS the table
     PANE
       <space>       mark a range here
       <enter>       copy marked range to GOOD
       a             copy this region to GOOD
       A             copy the whole OUTPUT to GOOD
       d             remove from GOOD: the marked lines, or the region here
       j, <down>     down
       k, <up>       up
       <c-d>         a screen down
       <c-u>         a screen up
       h, <left>     scroll left
       l, <right>    scroll right
       w             next element that can vary or differs; the foot says what it is
       b             previous such element
       /             search down
       ?             search up
       <number>g     go to that OUTPUT line
     
     GLOBAL
       <tab>         switch pane
       u, <c-z>      undo
       r, <c-y>      redo
       R             reset: GOOD as it stood when the screen opened
       z             re-align: ask compare again
       t             the tolerance report: analogies, patterns, constraints
       e             edit GOOD here; <F5> ends the edit and re-aligns
       <F6>, <c-e>   edit the GOOD in $EDITOR
       <F5>          the tolerance in memory, editable; <F5> tries it
       <F1>          this table
       s             save GOOD as it stands and leave; asks first
       S             save and leave, unasked
       q             leave without saving; asks first
       Q, <c-c>      leave without saving, unasked
       y             yes, to the question at the foot
       n             no; any other key means the same

-- the editing table (intend 21): letters type there
       <F5>          done: close the pane; what changed is re-aligned
       <Esc>         discard: close the pane; nothing changes
       <F6>, <c-e>   this text in $EDITOR; its exit ends the edit
       <c-z>         undo, in this text
       <c-y>         redo, in this text

-- no key is bound twice
     keyed   : none
     editing : none
     fallback: none

-- the fallback speaks the SAME acts
     t    -> TAKE_ALL
     e    -> EDIT
     c    -> DONE
     q    -> CANCEL

-- an unbound key means nothing, and that is not an error
     act_of('Z') = None
<hwut-end>
